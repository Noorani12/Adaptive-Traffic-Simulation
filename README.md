# Adaptive Traffic Signal Simulation

A Python-based traffic intersection simulation that compares **fixed-time traffic signal control** with a **queue-based adaptive control strategy**.

The project models vehicle arrivals at a four-way intersection and evaluates both approaches using **cumulative waiting time** and **vehicle throughput**.

## Project Overview

Traditional fixed-time traffic signals assign a predetermined green duration to each direction regardless of traffic conditions.

This project compares that approach with an adaptive strategy that adjusts the green duration according to the current queue length.

The simulation aims to demonstrate how dynamically allocating green time based on traffic demand can affect:

* Vehicle waiting time
* Queue buildup
* Traffic throughput
* Signal scheduling

## How the Simulation Works

The simulation runs for a fixed number of time ticks.

At each tick:

1. Random vehicle arrivals are generated for each direction.
2. The same arrivals are provided to both controllers for a fair comparison.
3. Vehicles waiting in each queue contribute to cumulative delay.
4. Vehicles are allowed to pass through the currently green direction.
5. The green timer is updated.
6. When the timer expires, the signal switches to the next direction.

Two separate controllers are simulated:

* **Fixed Controller** — uses a constant green duration of 10 ticks.
* **Adaptive Controller** — calculates green duration from the current queue length.

## Adaptive Scheduling Logic

The adaptive controller estimates the required green duration using the current queue:

```text
calculated_green = max(G_MIN, int(queue_length / SATURATION_FLOW) + 2)
green_time = min(G_MAX, calculated_green)
```

Where:

* `G_MIN = 3` — minimum green duration
* `G_MAX = 20` — maximum green duration
* `SATURATION_FLOW = 2` — maximum vehicles that can pass per tick

Therefore, larger queues receive longer green windows, while the minimum and maximum limits prevent the calculated duration from becoming too small or too large.

## Simulation Parameters

| Parameter              |           Value |
| ---------------------- | --------------: |
| Simulation time        |       150 ticks |
| Minimum adaptive green |         3 ticks |
| Maximum adaptive green |        20 ticks |
| Saturation flow        | 2 vehicles/tick |
| North arrival rate     |             0.3 |
| South arrival rate     |             0.3 |
| East arrival rate      |             0.1 |
| West arrival rate      |             0.8 |

The higher West arrival rate creates a heavier-traffic approach, allowing the adaptive strategy to respond to different traffic conditions.

## Performance Metrics

The simulation compares the two strategies using:

### Total Delay

The cumulative waiting time generated by vehicles remaining in queues throughout the simulation.

### Throughput

The total number of vehicles that successfully pass through the intersection.

The program also calculates the percentage improvement of the adaptive approach relative to the fixed-time approach.

## Fair Comparison

Both controllers receive **the same randomly generated traffic arrivals at every simulation tick**.

This makes the comparison more meaningful because differences in performance are caused by the signal-control strategy rather than different traffic inputs.

## Algorithmic Approach

The project uses a **queue-based heuristic scheduling approach**.

The controller:

1. Observes the current queue length.
2. Estimates the green time required to serve the queue.
3. Adds a small scheduling buffer.
4. Enforces minimum and maximum green-time limits.
5. Continues cycling through all four directions.

This is a heuristic adaptive-control strategy rather than a full optimization algorithm.

## Limitations and Future Extensions

The current project is a **simulation prototype** and does not include:

* Real camera-based vehicle detection
* Computer vision
* Pedestrian detection
* Genetic Algorithm or other advanced optimization algorithms
* Coordination between multiple intersections
* Real-world traffic signal hardware

Possible future extensions include integrating vehicle detection from camera feeds and replacing the current heuristic with more advanced optimization techniques.
